## `guidellm benchmark from-file` → `guidellm export`(v0.7.2)

저장된 벤치마크 보고서를 불러오고 필요에 따라 데이터를 다시 내보냅니다.

**v0.7.2**에서는 `benchmark` 명령어 그룹이 제거되고, `guidellm benchmark from-file`가 최상위 명령어 `guidellm export`로 대체되었습니다. 그 밖의 동작과 옵션은 v0.7.0/v0.7.1의 `from-file` 명령어와 같습니다.

| 옵션                                                                                                                                                                           | 대체 설정                                                                                                  |
| :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------- |
| PATH 저장된 벤치마크 보고서 파일의 경로(기본값: ./benchmarks.json)                                                                                                             | 기존과 동일                                                                                                |
| --output-path 다시 내보낼 벤치마크 결과를 저장할 디렉터리 또는 파일 경로. 디렉터리이면 모든 형식의 출력을 그 위치에 저장하고, 파일이면 일치하는 형식의 출력을 해당 파일에 저장 | 삭제됨. 대신 `--output` 사용                                                                               |
| --output-formats 벤치마크 결과의 출력 형식(예: console, json, html, csv)                                                                                                       | `--output`으로 유형과 경로 지정. 예: `--output kind=console` 또는 `--output kind=json,path=benchmark.json` |

## `guidellm config`

설정값을 표시합니다.

GuideLLM 동작에 영향을 주는 환경 변수를 표시하는 명령어임을 명확히 하기 위해 `guidellm config`에서 `guidellm env`로 이름이 변경되었습니다.

`guidellm config`는 이후 `run` 옵션에서 YAML 설정 파일을 생성하는 용도로 사용할 예정입니다.

| :----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | :--------------------------------------------------------------------------------------------------------------------------------------------- |
| data(위치 인자)                                                                                                                                                                                                                                                          | 데이터셋 설정 사용. 예: `kind=huggingface,source=<id>`                                                                                         |
| output_path(위치 인자)                                                                                                                                                                                                                                                   | 결과 파일 경로. 예: `file.json`                                                                                                                |
