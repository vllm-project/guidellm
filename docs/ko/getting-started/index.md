# 시작하기

GuideLLM에 오신 것을 환영합니다! 이 섹션에서는 도구 설치부터 벤치마킹 환경 설정, 첫 벤치마크 실행 및 결과 분석까지의 과정을 안내하여, 실제 운영 환경의 추론 워크로드에 맞게 LLM 배포 환경을 최적화할 수 있도록 지원합니다.

GuideLLM은 대규모 언어 모델의 배포 환경을 손쉽게 평가하고 최적화할 수 있도록 지원하며, 성능, 리소스 활용도 및 비용 효율성 사이에서 최적의 균형을 찾는 데 도움을 줍니다.
