# GuideLLM 行为准则

## 我们的承诺

作为社区成员、贡献者和领导者，我们承诺营造一个人人都能免受骚扰、积极参与社区的环境，不因年龄、体型、可见或不可见的残障、族裔、性征、性别认同与表达、经验水平、教育程度、社会经济地位、国籍、外貌、种族、宗教、性身份或性取向而有所区别。

我们承诺以有助于建设开放、友好、多元、包容且健康的社区的方式行事和互动。

## 我们的行为标准

有助于为社区营造积极环境的行为包括：

- 对他人展现同理心和善意
- 尊重不同的意见、观点和经历
- 提出建设性反馈，并以恰当的方式接受反馈
- 为自己的错误承担责任，向受影响者道歉，并从中吸取教训
- 不只考虑个人利益，也关注整个社区的福祉

不可接受的行为包括：

- 使用带有性意味的语言或图像，以及任何形式的性关注或性挑逗
- 网络挑衅、侮辱或贬损性评论，以及人身或政治攻击
- 公开或私下骚扰
- 未经明确许可，公开他人的私人信息，例如住址或电子邮箱地址
- 其他在专业环境中可被合理认定为不当的行为

## 执行责任

社区领导者负责阐明并执行我们的行为标准。当他们认为某种行为不当、具有威胁性、冒犯性或造成伤害时，应采取适当且公正的纠正措施。

社区领导者有权也有责任删除、编辑或拒绝不符合本行为准则的评论、提交、代码、Wiki 编辑、议题和其他贡献；在适当情况下，他们会说明审核决定的理由。

## 适用范围

本行为准则适用于所有社区空间；当个人在公共场合正式代表社区时，也同样适用。代表社区的情形包括使用官方电子邮箱地址、通过官方社交媒体账号发帖，或作为指定代表参加线上或线下活动。

## 举报

如遇到辱骂、骚扰或其他不可接受的行为，可通过 GitHub、Slack 或电子邮件向负责执行准则的社区领导者举报。所有投诉都会得到及时、公正的审查和调查。

所有社区领导者都有义务尊重事件举报者的隐私和安全。

## 执行指南

社区领导者在决定违反本行为准则的行为应受到何种处理时，将遵循以下社区影响指南：

### 1. 纠正

**对社区的影响**：使用不当语言，或出现被认定为不专业或令社区成员不适的其他行为。

**处理措施**：社区领导者会私下发出书面警告，明确说明违规行为的性质以及其不当之处；也可能要求当事人公开道歉。

### 2. 警告

**对社区的影响**：单次事件或一系列行为构成违规。

**处理措施**：发出警告，并说明再次违规将面临的后果。在指定期限内，不得与相关人员互动，包括不得主动联系行为准则执行者。这一限制适用于社区空间以及社交媒体等外部渠道。违反这些要求可能导致临时或永久封禁。

### 3. 临时封禁

**对社区的影响**：严重违反社区标准，包括持续出现不当行为。

**处理措施**：在指定期限内，暂时禁止当事人以任何形式与社区互动或公开交流。在此期间，不得公开或私下联系相关人员，包括不得主动联系行为准则执行者。违反这些要求可能导致永久封禁。

### 4. 永久封禁

**对社区的影响**：反复违反社区标准，包括持续骚扰、骚扰个人，或攻击、贬损特定群体。

**处理措施**：永久禁止当事人在社区内进行任何形式的公开互动。
