# 快速开始

欢迎使用 GuideLLM！本节将引导你安装工具、设置基准测试环境、运行首次基准测试并分析结果，帮助你针对真实推理工作负载优化大语言模型部署。

GuideLLM 让评估和优化大语言模型部署变得简单，帮助你在性能、资源利用率和成本效益之间找到合适的平衡。
